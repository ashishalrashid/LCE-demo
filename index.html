LexCorpusEngine

In-memory index-based search engine with BM25 ranking

GitHub · Rashid Project Repository

About the Project

LexCorpusEngine is a lightweight, in-memory search engine built entirely from scratch in Java. It implements an inverted index, BM25 ranking, and a trie-based autocomplete system with a strong focus on performance, correctness, and architectural clarity.

This demo runs on a locally indexed text corpus and exposes search, autocomplete, and document retrieval APIs via a custom HTTP server. The frontend is intentionally framework-free.

Key Features

  • Inverted index with BM25 ranking
  • Trie-based autocomplete with Top-K suggestions
  • Custom binary persistence format
  • Zero external dependencies
  • Latency-aware design
